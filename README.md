# StockWise

Inventory and stock decision-support system for a small electronics retailer.

The project lives in **[stockwise/](stockwise/README.md)**, split into two independent parts:

- [`stockwise/backend/`](stockwise/backend/) — TypeScript + SQLite JSON API
- [`stockwise/frontend/`](stockwise/frontend/) — browser UI and the server that serves it

See [stockwise/README.md](stockwise/README.md) for setup, scripts, architecture and documentation.
